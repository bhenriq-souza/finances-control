# Perfis de Usuário

| Perfil | Permissões |
|---|---|
| **ADMIN** | Gerenciar usuários, gerenciar contas, gerenciar permissões |
| **BILLER** | Gerenciar faturas, gerenciar pagamentos, gerenciar assinaturas |
| **VIEWER** | Visualizar faturas, visualizar pagamentos, visualizar assinaturas |

> O modelo de dados referencia estes perfis na entidade `UserProfile` (admin, biller, viewer). A concessão de privilégios é feita pelo usuário administrador (ver F001 em [requisitos de negócio](business-requirements.md)).
